# 漫步旅圖 DayTrip — 一日遊行程與預算規劃器

一個純前端（HTML / CSS / JavaScript）製作的台灣一日遊行程規劃網頁應用，整合**景點路線**、**四種交通工具路程與費用比較**、**必吃美食清單**、**互動式路線圖**與**即時預算分攤試算**。

## 功能特色

- **5 套台灣精選一日遊範本**：
  - 九份山城 × 十分瀑布 × 猴硐貓村鐵道一日遊
  - 淡水海景古蹟 × 北投溫泉文化微旅行
  - 台中草悟道 × 審計新村 × 逢甲夜市文青美食遊
  - 台南府城古蹟 × 國華街小吃 × 漁光島夕陽遊
  - 高雄駁二藝術特區 × 旗津渡輪海鮮 × 西子灣夕照
- **交通工具切換與比較**：支援大眾運輸、開車/計程車、騎機車、步行/單車，支援全程切換或單段個別設定。
- **互動式路線圖與 Google Maps 導航**：依站點座標自動繪製視覺化路線，點擊站點可聯動高亮行程，並提供全程與單點 Google Maps 連結。
- **即時預算試算**：分類統計交通、美食、門票與預備金，支援人數調整、自駕/計程車費用均攤與圓餅圖分析。
- **自訂編輯與匯出**：支援新增/編輯/排序/刪除站點（自動儲存於瀏覽器 `localStorage`），並可匯出純文字行程表或列印。

## 使用方式

直接以瀏覽器開啟 `index.html` 即可使用，無需任何後端或建置步驟。
